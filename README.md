## About

I care about the part of the web users actually touch: layout that holds up on a 360px screen, states that are handled before they break, and CSS that someone else can still read six months later.

Most of my work right now is building full interfaces from Figma mockups — responsive layouts, component systems, and the JavaScript that makes them behave. I write vanilla JS on purpose while I learn: it makes the framework layer easier to reason about later.

Outside the browser I use Python for scripting and small automation tasks.

## How I work

- **Mobile first, always.** The narrow layout is the hard one; the desktop version follows from it.
- **Semantics before classes.** A correct `<button>` beats a styled `<div>` with a click handler.
- **Small, readable commits.** A diff should be reviewable without a call.
- **Ship, then refine.** A working page in the browser teaches me more than another hour of planning.
