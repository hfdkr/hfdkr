**A multi-page web project focused on accessible, responsive user experiences.**

- Built front-end pages using HTML, Tailwind CSS, and JavaScript.
- Worked on interactive interfaces and client-side functionality.
- Developed a multilingual experience with French, Arabic, and English.
- Implemented interface features such as theme preferences and emergency-related screens.

**Technologies:** HTML · Tailwind CSS · JavaScript · localStorage

### 📋 Task_Flow — Task Management Project

A web application project exploring task management, server-side functionality, and application structure.

- Worked with JavaScript and Node.js.
- Explored Express.js routing and middleware.
- Practiced handling application data and user-related functionality.
- Worked with sessions and password hashing as part of the project.

**Technologies:** JavaScript · Node.js · Express.js · JSON storage

- Worked on a shopping cart counter and feedback messages.
- Explored localStorage to preserve cart-related state.

**Technologies:** HTML · Tailwind CSS · JavaScript · localStorage
